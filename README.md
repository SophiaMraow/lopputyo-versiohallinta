Ohjelmointivälineet ja versionhallinta kurssin lopputyö.

Lopputyön terminaali versio

Käytetyt komennot

git init
    aloittaa tyhjän git repon

git add
    lisää tiedoston repon seurantaan
    
git commit
    tallentaa muutokset repoon
    
git push
    siirtää muutokset githubiin tai muuhun remoteen (esim. codeberg)

git branch
    luo uuden haaran

git switch
    vaihtaa olemassa olevaan haaraan

git merge
    yhdistää haaroja 
    
git stash
    tallentaa muokkaukset tilapäisesti
    
git stash pop
    palauttaa stashiin palautetut tiedostot
