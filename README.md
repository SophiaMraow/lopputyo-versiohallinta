Ohjelmointivälineet ja versionhallinta kurssin lopputyö.

Lopputyön terminaali versio

Ongelmat ratkaisin hakemalla netistä, lukemalla gitin dokumentaatiota tai kysymällä kaverilta.

Opin gitin perus käyttöä komentoriviltä

Käytetyt komennot

git init
 - aloittaa tyhjän git repon

git add
 - lisää tiedoston repon seurantaan
    
git commit
 - tallentaa muutokset repoon
    
git push
 - siirtää muutokset githubiin tai muuhun remoteen (esim. codeberg)

git branch
 - luo uuden haaran

git switch
 - vaihtaa olemassa olevaan haaraan

git merge
 - yhdistää haaroja 
    
git stash
 - tallentaa muokkaukset tilapäisesti
    
git stash pop
 - palauttaa stashiin palautetut tiedostot
    
git revert
 - peruu valitun commitin. käytännössä tekee uuden commitin joka on valitun commitin vastakohta
    
git cherry-pick
 - valitsee tietyn commitin toisesta branchista ja committaa sen tämänhetkiseen
 
git tag
 - näyttää tai luo tageja
 
git rebase
 - päivittää haaran toisen haaran tilanteeseen
